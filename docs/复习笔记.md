# 一、错误复盘

## 错误一：括号未闭合导致连环报错

### 现象
编译报出 4 个错误：
```
',' expected
'}' expected
找不到 backgroundColor
```

### 根因
`List` 列表代码编辑到一半（半成品状态），导致括号不配对：

| 缺失位置 | 说明 |
|---------|------|
| `ForEach(...)` 的收尾 `)` | 回调 `}` 后缺 `)` 闭合 `ForEach` 调用 |
| `List(){...}` 子块的 `}` | List 子块未闭合，属性链 `.backgroundColor(...)` 无处挂载 |
| `struct Connect {` 的 `}` | 最外层组件块缺闭合 |

> 一句话：**括号不闭合 → 解析器把后续属性链误判为非法语法 → 报错如滚雪球**。

### 修复
逐层补全 `)` 和 `}`，使结构完整：
```
Column > (Row > Search) + List(ForEach > ListItem > Row(Image + Column(Text)))
```

### 教训
- 写嵌套组件时**逐层闭合、逐层检查**，不要留半成品
- 利用 IDE 的**括号配对着色**（光标移到括号上会高亮配对）
- 属性链（`.width(...)` 等）挂载在**它紧邻的组件**上，注意层级别错位

## 错误二：远程图片不显示 / 不可点击打开

### 现象
1. 头像（远程 URL）加载不出来，显示空白
2. 点击头像没有任何反应（期望：打开大图预览）

### 根因
1. **没有网络权限**：头像用的是远程地址
   ```typescript
   user_picture: 'https://api.dicebear.com/9.x/adventurer/svg?seed=user1'
   ```
   而 `module.json5` 里没有声明 `ohos.permission.INTERNET`，系统禁止应用联网 → 图片无法加载
2. **没有绑定点击事件**：`Image` 组件没有 `.onClick()`，自然无法打开大图

### 修复
**① 加网络权限**（`module.json5`）：
```json5
"requestPermissions": [
  { "name": "ohos.permission.INTERNET" }
]
```

**② 给头像加点击事件 + 全屏预览层**（`connect.ets`）：
```typescript
@State previewVisible: boolean = false
@State previewUrl: ResourceStr = ''

Image(item.user_picture)
  .onClick(() => {
    this.previewUrl = item.user_picture
    this.previewVisible = true
  })
```

```typescript
// 全屏预览层（用 Stack 覆盖在列表上方）
Stack() {
  Column() { /* 原列表内容 */ }
  if (this.previewVisible) {
    Stack() {
      Image(this.previewUrl)
        .width('100%').height('100%')
        .objectFit(ImageFit.Contain)
        .onClick(() => { this.previewVisible = false })
    }
    .width('100%').height('100%')
    .backgroundColor('#CC000000')   // 半透明黑幕
    .zIndex(10)                      // 置顶
  }
}
```

### 知识点
- 远程资源（图片等）**必须**声明 `INTERNET` 权限才能加载
- "打开大图" = 用一个**全屏覆盖层**叠加在当前页面上（Stack + if 条件渲染）

## 错误三：点击方块不变色（背景遮挡）

### 现象
给 `ListItem` 设置了 `stateStyles` 的 `pressed` 按压变色，但点击时方块颜色毫无变化。

### 根因 —— 背景被遮挡
```
ListItem()                        ← stateStyles 挂在这（外层）
  └── Row                         ← 你看到的"方块"（内层）
        .backgroundColor(Color.White)   ← 硬编码白色，铺满并盖住下层
```

- `stateStyles` 的 `pressed` 样式挂在**外层 `ListItem`** 上
- 但内部 `Row` 硬编码了 `.backgroundColor(Color.White)` 且铺满整个内容区
- 按下时 `ListItem` 背景**确实变了**，但**全被白色 Row 盖住** → 视觉上"没变色"

### 修复 —— 让"可见的方块"自己响应按压
```typescript
Row({space:10}) { ... }
.width('100%')
.padding({left:12,right:12,top:8,bottom:8})
.stateStyles({                       // ← 移到可见的 Row 上
  normal:  { .backgroundColor(Color.White) },
  pressed: { .backgroundColor('#EBEDEF') }
})
```

### 知识点
- 哪个组件**可见**，变色样式就挂**在哪个组件上**
- 内层组件有背景色会**盖住**外层组件的背景 → 排查"为什么没效果"时要先想"是不是被盖住了"
- `List` 容器自带滚动手势，会优先判断是否滑动 → 按压变色可能**延迟几十毫秒**，这是系统机制，属正常现象

# 二、知识点整理

## 1. ArkUI 状态管理装饰器

| 装饰器 | 作用 | 使用场景 |
|--------|------|---------|
| `@State` | 组件**内部**可变状态，改变时自动刷新 UI | 列表数据、开关状态、预览开关 |
| `@Prop` | 父组件传入的**单向**数据（子组件内只读，但可提供默认值） | 传参给子组件 |
| `@Link` | 父组件传入的**双向**数据（与父组件同步） | 需要回传修改的共享状态 |

> ⚠️ 注意：`@Link` / `@Prop` 如果**组件内根本没用**，就改成 `@Prop` 并提供默认值，避免调用方必须传参的麻烦。

```typescript
@Prop message: string = ''           // 可无参使用
@State userlist: UserInfomModel[] = []
@State previewVisible: boolean = false
```

## 2. ForEach 列表渲染

```typescript
ForEach(
  数据源数组,
  (item, index) => {   // 每一项的生成函数
    ListItem() { /* 根据 item 渲染 */ }
  }
)
```

要点：
- `ForEach` 写在 `List(){ }` 内部，每个 item 生成一个 `ListItem`
- 每个 item 的样式、事件是**独立的**（每项都有自己的一套）
- 修改数据源数组 → ForEach 自动局部刷新（不需要手动刷新）

## 3. Stack 层级布局与全屏覆盖

- `Stack` 让子组件**层叠**排列，后面的盖在前面
- 配合 `if` 条件渲染 + `zIndex` 实现"弹层 / 预览层 / 遮罩"
- 全屏覆盖层经典写法：
  ```typescript
  Stack() {
    主内容
    if (条件) {
      Stack() { 弹层内容 }
        .width('100%').height('100%')
        .backgroundColor('#CC000000')   // 半透明黑幕
        .zIndex(10)
    }
  }
  ```
- 弹层内容点击关闭：给覆盖层加 `.onClick(() => { 条件 = false })`

## 4. Image 组件与网络图片权限

```typescript
Image(item.user_picture)      // 支持 ResourceStr：字符串URL / $r资源 / 资源引用
  .width(44).height(44)
  .borderRadius(22)           // 圆形头像 = 边长一半
  .objectFit(ImageFit.Contain) // Contain: 完整显示不裁剪
  .onClick(() => { /* 点击事件 */ })
```

- **远程图片必须配 `ohos.permission.INTERNET` 权限**，否则加载失败
- 本地资源用 `$r('app.media.xxx')`
- `ImageFit` 常用值：`Contain`（完整显示）、`Cover`（填满裁剪）、`Fill`（拉伸）

## 5. stateStyles 多态样式

为组件在**不同状态**下设置不同样式，进入该状态时框架自动套用：

```typescript
.stateStyles({
  normal:   { .backgroundColor(Color.White) },   // 常态
  pressed:  { .backgroundColor('#EBEDEF') },     // 按下
  disabled: { .opacity(0.4) },                    // 禁用
  focused:  { .borderWidth(1) },                  // 聚焦
  clicked:  { ... }                               // 点击后（悬停等）
})
```

关键规则（踩坑点）：
- **挂在可见组件上**，否则被内层背景遮挡看不到
- 组件内**不要重复硬编码**该属性，否则盖住 stateStyles 的效果
- `List`/`Grid` 容器内，按压识别可能因内置滑动手势**延迟**

## 6. module.json5 权限配置

```json5
{
  "module": {
    "name": "entry",
    "requestPermissions": [
      { "name": "ohos.permission.INTERNET" }
    ],
    "abilities": [ /* ... */ ]
  }
}
```

- 新增系统能力（联网、定位、相机等）必须在此声明
- 常见权限：`ohos.permission.INTERNET`（联网）、`ohos.permission.CAMERA`（相机）、`ohos.permission.LOCATION`（定位）

# 三、自查清单

写/改完代码后按顺序检查：

- [ ] **括号配对**：`(` 配 `)`、`{` 配 `}`，每层嵌套是否闭合
- [ ] **属性链归属**：`.width(...)`、`.backgroundColor(...)` 挂在哪个组件上？层级对不对？
- [ ] **状态装饰器**：数据会变吗？变了要刷新 UI 吗？用了 `@State` 吗？
- [ ] **列表渲染**：数据是数组吗？`ForEach` 写在 `List`/`Grid` 里了吗？每一项是 `ListItem`/`GridItem` 吗？
- [ ] **新增页面**：注册到 `main_pages.json` 了吗？
- [ ] **新增系统能力**：`module.json5` 里加 `requestPermissions` 了吗？
- [ ] **远程资源**：联网权限配了吗？
- [ ] **点击无效果**：先想"是不是被内层组件背景/内容盖住了"？
- [ ] **变色无效果**：`stateStyles` 是挂在"可见的组件"上吗？组件里有硬编码同属性吗？
- [ ] **编译后**：跑一遍构建，确认 `Build Success`
